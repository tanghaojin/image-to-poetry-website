# CText 与汉籍电子文献数据库接入评估

日期：2026-09-12

## 中国哲学书电子化计划 CText

- 提供官方 JSON API：`https://api.ctext.org/`。
- API 支持 CORS，实测 `getstatus` 从 `http://localhost:3100` 请求返回 200。
- 实测未登录、非订阅身份请求章节正文时返回 `ERR_REQUIRES_AUTHENTICATION`。
- 官方说明未认证用户只能访问有限数据；完整作品结构通常需要登录、订阅机构 IP 或 API Key。
- API 仍标记为预发布，函数、参数和响应格式可能调整。
- 官网 FAQ 禁止使用自动下载软件批量下载页面；站点内容再发布通常需要明确许可。
- Data Wiki RDF 有公开批量下载，但采用 CC BY-NC-SA 3.0，仅适合非商业用途，而且主要是知识图谱数据，不等于完整诗词正文库。
- 《全唐诗》等资料存在 Wiki/OCR 内容，部分页面明确标记为自动 OCR，不能把“来自 CText”直接等同于“正文已经校勘”。

结论：适合作为人工校验、来源链接和少量合理 API 查询，不作为产品的批量诗词采集源。若需要稳定批量使用，应向项目方申请机构/API授权并确认再发布范围。

## 中央研究院史语所汉籍电子文献数据库

- 实测网站首页和查询入口返回 200。
- 没有发现面向第三方应用的公开 API 文档。
- 响应没有面向 `http://localhost:3100` 的 CORS 许可，前端不能直接调用。
- 用户提供的查询 URL 含会话和内部查询状态，不适合作为永久数据链接。
- 官方使用办法将其定位为非营利学术研究数据库，个人或机构访问采用账号和固定 IP 管理。
- 官方规则明确限制以浏览下载方式复制数据库内容，并限制商业营利用途。

结论：适合作为具备相应访问资格时的人工交叉核查来源。当前公开条件不适合自动抓取、批量入库或作为线上生产接口。需要产品化使用时，应先取得史语所明确授权或合作许可。

## 对“见景寻诗”的建议

1. 诗词正文仍使用许可证清晰、可再发布的数据源，并进行项目内校验。
2. CText 只保存作品页面链接、版本说明和人工核查结论，不批量镜像页面。
3. 汉籍数据库只记录书名、卷次等引用信息，不复制其数据库整理内容。
4. 数据库保留最小来源字段：`source_name`、`source_url`、`verification_note`、`verified_at`。
5. 对自动 OCR 页面增加 `ocr_unverified` 标记，不进入正式匹配库。
6. 只有 `verification_status = verified` 的诗词可以返回给用户。

## 实测摘要

| 项目 | CText | 汉籍数据库 |
|---|---|---|
| 网站访问 | 可访问，主站对部分自动请求返回 403 | 可访问 |
| 公开 API | 有 JSON API | 未发现 |
| CORS | API 支持，回显请求 Origin | 未返回 CORS 许可 |
| 未认证正文 | 实测要求认证 | 通过网页会话/账号查询 |
| 批量复制 | 官方限制自动批量下载 | 官方限制浏览下载复制 |
| 商业产品直接入库 | 需单独确认授权 | 需单独取得授权 |
| 推荐用途 | 校验与来源链接 | 人工交叉核查 |
